# 대결 모드 최종 결정 (Claude·Codex 초안 종합, 2026-11-11)

세부 표(견종 72종·기술 72개·아이템 30개·NPC 배치·화면)는 `docs/pet-battle-design-codex.md`를 기준 자료로 쓴다. 아래 결정이 그 문서와 다르면 **이 문서가 우선**이다.

## 둘이 같은 점
- 사람 NPC 한 명 + 강아지 한 마리와 1대1 턴제. 우리 쪽은 도미(골든 리트리버)·미네(말티즈) 중 하나. 한 판 6~10라운드, 1~2분, 최대 12라운드 후 판정.
- 싸움이 아니라 달려들기·자리 차지하기·장난감 겨루기로 표현. HP는 "버틸 힘". 부상·사망 없음.
- 자원은 기력(최대 10, 시작 6, 라운드마다 +2, 숨 고르기 +4). 상대의 다음 행동을 미리 보여 준다.
- 패배 불이익 없음. 매 판 꽉 찬 상태로 시작(여러 사람이 같은 강아지로 동시에 싸워도 서로 영향 없음).
- 전투 레벨(1~30)은 돌보기 레벨과 분리. 전투 레벨업 코인은 없음. 승리 코인 2~6(공용 지갑, 일일 상한).
- 특정 게임의 이름·수식·기술명·그림을 쓰지 않는 독자 설계.

## 화면 힌트
기술 버튼에 "효과가 좋아요 / 평범해요 / 잘 안 통해요" 3단 표시, 길게 누르면 실제 배율과 예상 피해.

## 구현 순서
1. **엔진과 데이터(SQL 없음, 화면 없음)**: `lib/domine/battle/` 순수 함수 + 12종·24기술·8아이템 + 시뮬레이션 테스트(승률 표).
2. **전투 화면(보상 없음)**: 지도 칸의 NPC 조우, 전투 장면, 결과. 실제 폰 화면에서 확인.
3. **v11 SQL**: 티켓·정산·전투 레벨·전투 장비(강아지별)·견종 도감·일일 상한. 사용자가 실행.
4. **견종 이미지 12종**(Codex 이미지 생성) → 이후 12종씩 확장, 고정 강자 5명.

## 남은 쟁점
- 승리 위조는 막지 못한다(시드·최소 시간은 완화일 뿐). 일일 보상 상한으로 피해를 제한한다.
- 시뮬레이션 전에는 수치가 검증되지 않은 시작값이다.
