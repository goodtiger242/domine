**우선 도입할 것은 행동 예고·기술 선택·상성·패시브입니다.** 장비 강화와 공동 보스는 그 뒤가 적합합니다. 아래 ‘검증’은 실제 게임에서 쓰이는 구조라는 뜻이며, 재미·적용안·난이도는 이 게임 조건에 대한 설계 판단입니다.

난이도의 **클라만**은 전투 규칙·화면 구현 기준입니다. 공용 강아지의 성장·장비·도감은 SQL 저장이 필요하고, 공동 보스·랭킹·시간 제한은 서버에서 중복 처리와 시간을 관리해야 합니다.
