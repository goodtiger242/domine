# 펫 키우기 게임 패턴 모음 (도미네 강아지 게임 적용용)

2026-11-11 작성. 출처가 다른 세 묶음을 구분한다.

- **[관찰]** REA로 실제 웹 펫 게임 한 곳의 스크립트를 받아 읽은 것: WebPet (https://robthepcguy.github.io/WebPet/, script.js 704줄). 코드·그림은 가져오지 않고 구조만 참고한다.
- **[자료]** 게임 연출(게임 필) 일반 자료: 눌림·늘어남, 대기 숨쉬기, 전환 0지연, 스프링 등. (joshwcomeau.com/animation/squash-and-stretch, GDevelop Character Game Feel, GameMaker "Juicing your movements")
- **[통념]** 다마고치·닌텐독스·네코아츠메·Pou 같은 상용 펫 게임에 대해 널리 알려진 구성. 직접 뜯어 본 것이 아니므로 참고 수준이다.

상용 모바일 게임 앱은 뜯어 보지 않았다(설치 파일이 없고, 뜯어 본 결과를 옮기면 저작권 문제가 생긴다). 두 번째 웹 게임(lrusso VirtualPet)은 스크립트가 수집 한도(64KB)를 넘어 읽지 못했다.

## 1. 진행 (수치와 선택)

| 패턴 | 출처 | 도미네에 적용 |
|---|---|---|
| 행동마다 **얻는 것과 잃는 것**이 있다: 먹이 +50이면 잠 −20·놀이 −30, 놀이 +50이면 잠 −20·배고픔 −30 | 관찰 | 지금은 행동이 수치를 올리기만 한다. 놀이·산책·훈련은 배부름을 조금, 목욕은 기분을 조금 깎아 "다음에 뭘 해 줄까"가 생기게 한다 |
| 수치를 **20/40/60/80 구간**으로 나눠 표정을 바꾼다(눈=졸림, 입=배고픔) | 관찰 | 얼굴 하나가 아니라 수치별 신호를 따로: 배고픔은 밥그릇 쪽을 보기, 더러움은 몸 긁기, 심심함은 공 물고 오기 |
| 구간에 처음 들어설 때 **한 번만** 알림(notified 표시) | 관찰 | "도미가 배고파해요"를 구간 진입 때 한 번만 말풍선으로. 반복하지 않는다 |
| 가득 찬 뒤 조금 더(120%) 받아 두는 여유 | 관찰 | 가득 찬 상태에서 한 번 더 주면 "배불러요" 반응만 하고 보상은 그대로 |
| 낮/밤 모드 전환 | 관찰 | 이미 시간대 배경이 있음. 밤에는 하품·졸린 걸음을 추가 |
| 짧은 주기 반복(1~2분에 한 바퀴): 요구 발생 → 행동 → 즉시 반응 → 작은 보상 → 다음 목표 표시 | 통념 | 보상 직후 "다음 레벨까지 N", "노랑 반다나까지 N코인"을 한 줄로 |
| 수집은 "아직 못 본 것의 윤곽"을 보여 준다 | 통념 | 도감 미발견 항목에 장소·시간 힌트("저녁의 당정역") |
| 방치해도 벌이 약하다(친구들이 같이 쓰는 게임) | 통념 | 수치가 낮아도 죽지 않음. 대신 축 처진 모습과 "보고 싶었어요" 복귀 인사 |

## 2. 모션 (강아지 움직임)

| 패턴 | 출처 | 구체 수치 |
|---|---|---|
| **대기 숨쉬기**: 가만히 있어도 살아 있게 | 자료 | 세로 1.00→1.03 배율, 2.4~3.2초 주기, 발 위치 고정(transform-origin 아래) |
| **눌림과 늘어남**(부피 유지) | 자료 | 착지: 가로 1.12 × 세로 0.90 → 120ms 뒤 복귀. 뛰어오름: 가로 0.92 × 세로 1.10. 곱이 1 근처 |
| **예비 동작**: 움직이기 전 반대로 살짝 | 자료 | 이동 전 80~120ms 동안 반대쪽 3% 기울임 또는 살짝 웅크림 |
| **전환은 0지연**: 누른 즉시 반응 시작, 꾸밈은 뒤에 | 자료 | 버튼 누름 → 50ms 안에 첫 움직임(고개 들기·귀 쫑긋) |
| **스프링 넘침**: 멈출 때 살짝 지나쳤다 돌아옴 | 자료 | `cubic-bezier(.34,1.56,.64,1)` 220~320ms |
| 걷기는 **위아래 튐 + 좌우 기울임**만으로도 걷는 느낌 | 자료·통념 | 한 걸음 260~320ms, 위아래 1.2~1.8(뷰박스 단위), 기울임 ±2.5° |
| 대기 중 **무작위 작은 행동** | 통념 | 6~14초마다 하나: 꼬리 흔들기, 고개 갸웃, 하품, 귀 긁기, 제자리 한 바퀴, 앉기 |
| 사람이 누른 곳을 **쳐다봄** | 통념 | 탭한 쪽으로 방향 전환 후 반응 |

## 3. 연출 (보상과 장면 전환)

| 패턴 | 출처 | 구체 수치 |
|---|---|---|
| **보상은 숫자가 날아가 쌓인다** | 통념 | 코인 3~5개가 강아지 위치에서 코인 표시로 400~600ms, 60ms 간격, 도착 때 숫자가 한 번 튐(1.0→1.25→1.0, 180ms) |
| 숫자는 **올라가며 센다** | 통념 | 300~500ms 동안 이전 값에서 새 값으로 |
| 레벨업은 **잠깐 멈춤 + 큰 연출** | 통념 | 0.9~1.2초: 배너, 반짝이 12개 안팎, 진동 [15,40,20] |
| 누른 버튼은 **눌린다** | 자료 | 90ms 동안 0.94배, 뗄 때 스프링 복귀 |
| **지역 이동**: 나가는 방향으로 퇴장 → 화면 전환 → 반대편에서 입장 | 통념 | 퇴장 450ms, 배경 교차 200ms, 입장 450ms. 위쪽은 작아지며 떠오르고 아래쪽은 커지며 내려감 |
| 새 장소 도착 시 **이름 띠** | 통념 | 이름표가 0.2초 커졌다 제자리, 1.6초 뒤 작아짐 |
| 발견은 **반짝 → 물음표 → 공개** | 통념 | 강아지가 킁킁(600ms) → 느낌표 → 도감 카드가 뒤집히며 등장 |
| 움직임 줄이기 설정 존중 | 자료 | `prefers-reduced-motion`이면 이동·튐 대신 0.2초 교차 전환 |

## 4. 지금 게임에서 우선 적용할 것 (효과 큰 순)

1. 지역 이동 퇴장·입장 연출(방향별)과 도착 이름 띠.
2. 대기 숨쉬기와 6~14초 무작위 작은 행동.
3. 누름 반응 0지연 + 착지·뛰기 눌림과 늘어남.
4. 코인이 날아가 쌓이고 숫자가 올라가며 세는 보상 연출, 보상 뒤 "다음 목표" 한 줄.
5. 수치 구간(20/40/60/80)별 신호와 구간 진입 1회 알림.
6. 놀이·산책·훈련·목욕의 작은 대가(수치 맞교환). 서버 수치가 바뀌므로 SQL 필요.
7. 도감 미발견 항목의 장소·시간 힌트.
