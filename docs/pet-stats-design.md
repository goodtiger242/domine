# 강아지 스탯·성장 최종 결정 (Claude·Codex 초안 종합, 2026-11-11)

세부 수식과 서버 구조 초안은 `docs/pet-stats-design-codex.md`. 아래와 다르면 이 문서가 우선이다.

## 둘이 같은 점
- 스탯은 기존 엔진의 6개를 그대로 쓴다: **체력, 공격력, 방어력, 민첩, 집중, 침착**. 회피·치명타 같은 새 스탯은 만들지 않는다.
- 참고용 **전투력** 숫자 하나: `10 × (체력/4 + 나머지 5개 합)` 반올림.
- 전투 레벨 1~30(돌보기 레벨과 별개), 누적 경험치 `6(L−1)(L+4)`.
- 레벨마다 **분배 포인트 3점**(최대 87점). 성장의 80%는 견종별 자동, 20%는 분배. 체력 4 = 다른 스탯 1로 환산. 한 스탯에 전체의 40%까지만.
- 기술은 계수를 화면에 보여 준다: 목록에는 "공격력 반영"처럼 짧게, 누르면 위력·반영 스탯·예상 피해·명중률.
- 장비는 비율 보정만(체력 +10%, 나머지 +8% 상한). 세트·강화·무작위 옵션 없음.
- 스탯 화면은 **성장 / 기술** 두 탭, 레이더 대신 숫자 붙은 가로 막대.
- 돌보기는 전투 능력치를 올리지 않는다. 대신 부족하면 깎인다(아래 표).

## 보상
승리 XP `min(24, 12 + 2×상대 레벨)`, 코인 2~6(공용 지갑). 무승부 XP 6, 패배 XP 4, 중단 0.

## 구현 순서
1. v17 SQL 한 번에: 전투 성장(XP·분배·숙련도), 전투 장비, 티켓·정산, 견종 도감, (로드맵의) 취향·친밀도·행동의 대가.
2. 스탯 화면(성장/기술 탭), 레벨업 연출, 대결 결과의 보상 표시.
3. 시뮬레이션 재검증: 분배 편중(집중·민첩), 장기전(체력·방어·회복), 숙련도 영향.

## 남은 위험
- 승리 위조는 막지 못한다(클라이언트 계산). 상대당 하루 1회 보상으로 피해를 제한한다.
- 누구나 분배할 수 있고 되돌릴 수 없다. 분배 전 확인창과 이력(누가 어디에 올렸는지)으로 실수를 줄인다.
