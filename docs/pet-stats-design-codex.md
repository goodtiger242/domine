**결정안: 기존 6개 스탯을 유지하고, 자동 성장 80%·분배 성장 20%를 적용한다.** 친구들은 함께 경험치를 모으고, 공용 육성 설정의 직접 변경은 관리자만 맡는다. 아래 수치는 구현 전 검증할 초깃값이며, 파일·코드·DB는 변경하지 않았다.

### 스탯과 전투 역할

| 내부 키 | 화면 이름 | 전투에서 하는 일 |
|---|---|---|
| hp | 체력 | 화면에서는 ‘버틸 힘’으로 설명. 생존·회복량·12라운드 잔여 비율 판정 |
| attack | 공격력 | 돌진·교란·수호·인내 계열 공격의 피해 증가 |
| defense | 방어력 | 교감 계열을 제외한 공격의 피해 감소 |
| speed | 민첩 | 같은 행동 우선도에서 선공 결정, 상대 명중률 감소 |
| focus | 집중 | 추적·교감 공격의 피해, 명중률·상태 부여 확률 증가 |
| calm | 침착 | 교감 공격의 피해 감소, 상태 부여 저항 |

- **명중·상태 확률은 기존 공식으로 계산해 표시하고, 회피·치명타 스탯은 추가하지 않는다.** 이유: 집중과 민첩의 역할을 유지하면서 중복 투자를 줄인다.
- **전투력은 참고 숫자 하나만 둔다.** `반올림[10×(체력/4+나머지 5개 합)]`으로 계산하며 상성·기술·일시 효과는 제외한다. 이유: 성장 비교는 쉽게 하되 승률로 오해하지 않게 한다.

### 레벨업과 공용 분배

- **전투 레벨은 1~30, 돌보기 레벨과 별개다.** 이유: 기존 돌보기 진행을 전투 때문에 다시 설계하지 않는다.
- **레벨마다 분배 포인트 3점, 최대 87점이다.** 기본 스탯은 그대로 두고, 레벨로 증가하는 성장량만 자동 80%·분배 20%로 나눈다.
- 체력과 다른 수치의 단위 차이는 **체력 4 = 다른 스탯 1**로 환산한다. 이유: 체력에 분배할 때 손해 보거나 지나치게 유리해지는 일을 막는다.
- 정확한 계산은 기존 견종 성장치 `g`, 기존 성장 진행도 `q=min(L−1,19)+0.8×max(L−20,0)`를 사용한다.
- 환산 가중치 `w`는 체력 4·나머지 1, 견종 성장 예산 `U=Σ(g÷w)`로 정의한다.
- 스탯별 최종 성장량은 `0.8×g×q + 0.2×U×q×w×해당 분배점수÷전체 획득점수`다. Lv.1의 성장량은 0이며, 기본값에 더한 뒤 한 번 내림한다.
- **포인트는 레벨업 정산 시 서버가 추천 배분한다.** 견종 성장 비율을 따라 정수로 배정하므로 접속자가 없어도 성장하며, 반올림 오차 외에는 기존 성장에 가깝게 출발한다.
- **직접 분배는 관리자 전용이며, 일반 친구는 누구나 무료 미리보기를 한다.** 이유: 이름만 입력하는 접속 방식에서는 이름별 투표·권한으로 장난을 막을 수 없다.
- **한 스탯에는 전체 획득점수의 40%를 올림한 값까지 배분한다.** 추천 배분도 같은 제한을 따른다. 이유: 집중·민첩 몰아주기를 제한한다.
- **초기화 비용은 0코인, 강아지별 하루 1회다.** 전체 점수를 즉시 재분배하며 미사용점수는 남기지 않는다. 이유: 공동 지갑 소모와 잦은 설정 변경을 함께 막는다.
- 배분 변경에는 이전·이후 값, 서버 시각, 관리자 식별값을 남긴다. 버전이 다른 동시 요청은 거절하고 최신값을 다시 보여 준다.

### 기술과 스탯의 연결

- **24개 기술과 기존 `damageAt` 구조를 유지한다.** 공격 기초값은 `위력×(1+레벨/20)+공격용 스탯×0.45`, 방어 보정은 `40÷(40+방어용 스탯)`이다.
- 돌진·교란·수호·인내 공격은 **공격력 대 방어력**, 추적은 **집중 대 방어력**, 교감은 **집중 대 침착**으로 계산한다.
- **방어·보조 기술은 효과에 맞는 수치만 사용한다.** 방어 기술은 기존 피해 감소, 강화는 대상 스탯 +15%, ‘곁에서 쉬기’는 최대 체력의 12% 회복이다.
- 회복 총량은 한 판 최대 체력의 25%, 연속 방어는 기존처럼 약화한다. 이유: 체력 투자와 버티기의 곱효과를 제한한다.
- 기술 목록에는 `앞발 밀기 · 공격력 반영`처럼 짧게 표시하고, 누르면 `위력 12 / 공격력×0.45 / 상대 방어력 적용`과 예상 피해·명중률을 보여 준다.
- **계수 0.45를 ‘공격력의 45% 피해’로 쓰지 않는다.** 이유: 방어·상성까지 적용하기 전의 항이기 때문이다.
- **기술 레벨·스킬 포인트는 도입하지 않는다(0점).** 습득 레벨 1·5·10·18·26과 장착 최대 4개를 유지한다. 이유: 스탯 분배와 중복되는 공용 육성 결정을 줄인다.

### 장비와 아이템

- **기존 8개 아이템과 목줄·하네스·장식 슬롯을 유지하고, 장비는 비율 보정만 사용한다.** 이유: 레벨이 올라가도 기존 장비가 의미를 가진다.
- 계산 순서는 **기본값+성장 → 장비 → 전투 중 효과**다. 장비 비율은 합산하고 체력 +10%, 나머지 +8% 상한과 기존 최소 +1 처리를 유지한다.
- **세트·강화·무작위 옵션은 넣지 않는다.** 이유: 작은 장비 선택만으로도 충분히 육성 차이가 생긴다.
- 물그릇·돗자리는 기존 판당 1회 사용과 회복 상한을 따른다. 소지·착용은 강아지별 공용이고, 전투에 반입한 소모품은 티켓별로 예약한다.

### 경험치·보상·돌보기

- **누적 경험치 `6(L−1)(L+4)`를 유지한다.** 다음 레벨에는 `12L+24`, Lv.30까지 총 5,916 XP가 필요하다.
- 승리 보상은 **XP `min(24,12+2×상대 레벨)`**, 코인 `상대 등급+1`로 2~6개다. 무승부 XP 6, 패배 XP 4, 중단 0이며 무승부·패배 코인은 없다.
- 상대가 시작 시점의 강아지보다 **4레벨 이상 낮으면 연습 대결로 보상 0**이다. 이유: 쉬운 상대 반복이 가장 빠른 성장법이 되는 일을 막는다.
- 같은 날짜·지도 칸·상대 슬롯의 보상은 **도미·미네 각각 공용으로 한 번**만 지급한다. 이름을 바꿔도 다시 받을 수 없다.
- **강아지별 하루 XP 120, 두 마리 합산 전투 코인 하루 180**을 상한으로 둔다. 자정은 한국 시간이며 초과분은 부분 지급한다.
- **돌보기는 전투 능력치·기력·전투 XP를 올리지 않는다.** 기존 돌보기 성장과 반응으로 연결한다. 이유: 기존 실험에서 기력 +1이 도미 승률 +9.6%p·미네 +3.7%p로 비대칭이었다.
- 매 판 체력·기력·상태를 새로 시작하고, 다른 친구의 전투나 돌보기가 진행 중인 판의 수치를 바꾸지 않는다.

### 폰 화면

- **‘성장 / 기술’ 두 탭으로 나누고, 성장 탭은 한 화면에 담는다.** 이유: 6개 스탯과 기술 계수를 동시에 넣으면 글자가 작아진다.
- 성장 탭: 강아지 전환 → 전투 레벨·XP → 작은 전투력 숫자 → 스탯 6행 → `배분 미리보기` 버튼 순서다.
- **레이더 대신 숫자가 붙은 가로 막대**를 사용한다. 체력은 4로 환산한 공통 축으로 막대를 그리되 실제 숫자는 그대로 표시한다.
- 스탯을 누르면 기본·자동 성장·분배·장비 증가분을 펼친다. 일반 친구에게는 추천 배분과 변경 이력, 관리자에게는 ± 버튼과 일괄 적용을 보여 준다.
- 기술 탭은 장착 4개를 먼저 보여 주고 나머지는 접는다. 상세는 탭으로 열며 길게 누르기는 보조 동작으로만 제공한다.
- 본문 16px 이상·보조 14px 이상·터치 영역 44px 이상을 기준으로 한다. 작은 폰이나 확대 글자에서는 자연스러운 세로 스크롤을 허용한다.
- **레벨업 연출은 0.8초 이내**로 숫자 상승과 ‘추천 배분 3점 적용’을 표시한다. 여러 레벨 상승은 합쳐 보여 주고 모션 감소 설정을 따른다.

### v17 저장 구조와 RPC 초안

v17 한 번에 아래 구조를 추가하고, 기존 공용 지갑·돌보기 데이터는 재사용한다. 전투 레벨·최종 스탯은 XP와 배분에서 계산하며 중복 저장하지 않는다.

| 테이블 | 핵심 컬럼·제약 |
|---|---|
| `battle_growth` | `pet_id PK`, `xp`, `allocation jsonb`, `version`, `last_reset_date`; 점수 합·항목별 상한 검증 |
| `battle_inventory`, `battle_loadout` | 강아지별 수량·예약량, 슬롯별 착용·장착 기술·버전 |
| `battle_ticket` | 소유 세션, 강아지, 시작 스냅샷, 상대 키, 시드, 규칙 버전, 만료·정산 결과 |
| `battle_reward` | `ticket_id PK`, XP·코인·정산일; 공용 상대 보상 키의 중복 지급 방지 |
| `battle_daily` | 날짜·범위·대상 키별 지급량; 강아지 XP·공동 코인 상한 |
| `battle_growth_log` | 변경 요청 ID, 강아지, 변경 전후·시각·행위자 |
| `battle_rules` | 규칙 버전별 견종 성장·기술 습득·아이템·보상 설정; 적용 후 불변 |

공개 RPC는 `domine_pet_battle_v17(p_session text, p_request_id uuid, p_kind text, p_input jsonb) → jsonb` 하나로 통합한다.

- `state {pet}`: 성장·기술·장비·일일 잔여량 조회.
- `start {pet,cell_id,roster_date,expected_loadout_version}`: 서버 저장값으로 티켓 생성. 세션당 진행 티켓 1개.
- `finish {ticket_id,outcome,rounds,item_used}`: 서버가 티켓 기준 보상을 계산하고 XP·지갑·원장·예약을 한 트랜잭션으로 정산.
- `loadout {pet,expected_version,moves,equipment,consumable}`: 보유·슬롯·습득 조건을 검증하고 공용 설정 변경.
- `allocate {pet,expected_version,allocation,admin_capability}`: 서버에서 확인하는 관리자 자격으로만 재분배. 이름은 권한 근거로 사용하지 않는다.
- 세션은 접속 시 발급하는 비공개 난수 토큰이며 새 회원가입은 요구하지 않는다. 요청 ID 재시도는 같은 결과를 반환하고, 다른 내용 재사용은 거절한다.
- 테이블 직접 쓰기를 막고 RPC만 허용한다. 티켓 소유·만료·최소 경과 시간·규칙 버전·수량·상한을 서버에서 검사한다.
- 잠금 순서를 기존 경제 RPC와 통일하고, 전투 중 성장·착용 변경은 다음 티켓부터 반영한다.
- **클라이언트 전투의 승리 위조까지 증명하지는 못한다.** 보상 금액을 클라이언트에서 받지 않고, 중복 방지·공동 상한으로 피해를 제한한다.

### 밸런스 위험과 검증 기준

1. **집중·민첩 편중:** 집중은 피해·명중·상태, 민첩은 선공·회피를 함께 올린다. 추천·각 스탯 상한 배분을 같은 시드로 비교하고, 동급 평균 승률 개선이 추천 대비 10%p를 넘으면 계수를 조정한다.
2. **체력·방어·회복 장기전:** 체력 투자와 비율 회복·장비가 겹친다. 방어·회복을 활용하는 정책으로 평균 6~10라운드, 12라운드 도달률 15% 이하를 목표로 확인한다.
3. **견종·상성·성장 구간 편향:** 기존 동급 상대별 승률도 도미 22.0~87.7%, 미네 23.3~94.0%로 넓다. Lv.1·5·10·18·20·21·26·30, 상대 ±3레벨, 무장비·최대 장비에서 평균 승률 10%p 초과 역전을 추적한다.

검증은 대표 조합 40시드로 먼저 보고, 조정 후 최종 300시드로 확인한다. NPC에도 같은 성장 예산의 추천 배분을 적용하며, 기존 무작위·탐욕 정책에 상대 예고를 활용하는 정책을 추가한다. 동시 정산·재분배·한국 시간 자정 경계는 별도 트랜잭션 테스트로 검증한다.
