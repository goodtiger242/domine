# 동네 싸움왕 — 최종 결정 (2026-11-11)

세부 표(10구역, 개 32견종·고양이 12형·야생 10종×2형, 512개체 생성 규칙, 네임드 35마리, 5직업·전용 기술 30개, 장비, 칭호, 공동 대장, 경제, v17 스키마, 8단계 로드맵)는 `docs/pet-king-design-codex.md`가 기준 자료다. 아래와 다르면 **이 문서가 우선**이다(사용자 결정 포함).

## 뼈대 (Codex 초안 채택)
- 목표: 도미·미네가 동네 싸움왕에 오른다. 100칸을 10개 구역(2열×5행)으로 묶고, 칸 대장 → 구역 대장(Lv.10~64) → 길목 강자 4 → 현 싸움왕.
- 동물: 12종(개 32견종, 고양이 12형, 비둘기·까치·참새·오리·청설모·너구리·고라니·멧돼지 등 10종×2형). 개체는 이름·별명·주인 유무·외형 변형(털·색·흉터·옷·소품)으로 512마리 + 네임드 35마리. 그림은 기본 그림 위에 레이어를 겹쳐 늘린다.
- 레벨 상한 999. 누적 XP `C(L) = 6(L−1)(L+4) + floor(max(0, L−10)³/25)`.
- 직업 5개(돌격·수비·기교·추적·교감), 전직 3단계(Lv.10/30/60, 구역 인증 조건), 직업 보정 최대 +8%/+8%/−8%.
- 스탯 6개, 레벨당 포인트 3점, **재분배 불가**(사용자 결정).
- 장비 확정 강화(실패·파괴 없음), 칭호, 동물 도감 보상, 공동 구역 대장(친구들의 기여 누적), 서열 랭킹. 퀘스트·출석 없음.
- 전투 계산은 클라이언트, 서버는 티켓·정산·성장 저장. 접속은 이름 입력 그대로. **SQL은 v17 한 번**을 목표.

## 사용자 결정으로 초안과 달라지는 것
| 항목 | 초안 | 최종 |
|---|---|---|
| 돌보기와 전투 | 세 수치 60 이상이면 XP +10% | **컨디션 감소**: 배부름·기분·청결이 부족하면 능력치 %감소(수치별 40~59 −5%, 20~39 −10%, 20 미만 −15%, 합산 최대 −30%). 상대 동물도 개체별 컨디션을 가지며 전투 전 카드에 표시 |
| 출몰 | 명단 고정 배치 | 명단(개체)은 고정이되 **출몰은 무작위**: 30분 구간마다 칸별 30% 확률, 한 칸에 0~여러 마리, 빈 칸 있음. 네임드는 정해진 칸·조건 |

| 문구 | — | 중복 없이 꼭 필요한 것만 |

## 외부 무료 자산 (사용자 제안)
- 이펙트·아이콘·UI는 무료 공개 자산을 적극 쓴다. **CC0(표기 불필요)** 우선: Kenney(kenney.nl), OpenGameArt의 CC0 묶음. **CC BY**(game-icons.net 등)는 화면의 "만든 이들" 목록에 출처를 적는다. 라이선스가 불분명한 것은 쓰지 않는다.
- 쓰는 자산은 `docs/pet-credits.md`에 이름·출처·라이선스를 기록한다.
- 동물 그림은 기존 실사풍과 맞아야 해서 Codex 생성(기본 그림 + 레이어)을 기본으로 한다.

## 구현 순서 (병렬로 나눈다)
1. **엔진 기반**(SQL 없음): 999레벨·성장식·분배 계산, 크리티컬, 컨디션 감소, 기력 0~8 기술 운용 타입, 종·서식지 상성, 시뮬레이션.
2. **콘텐츠 데이터**(SQL 없음, 1과 병렬): 종·품종 표, 개체 생성기(512), 네임드, 확대된 기술 표, 직업 트리.
3. **그림**(병렬): 개 20, 고양이 12, 야생 20, 레이어(흉터·옷·소품), 기술 이펙트·아이콘(무료 자산 + 생성).
4. **v17 SQL 한 번**: 성장·분배·숙련도·직업·장비·티켓·정산·출몰 처치 공유·중계·이력·공동 대장.
5. **화면**: 장면 속 동물 조우, 스탯·기술·직업 창, 도감, 서열, 공동 대장, 컷인 연출.

## 이질적인 그림과 엉뚱한 상대 (사용자 결정, 2026-11-11)
- 그림풍이 맞지 않는 무료 자산도 **일부는 일부러 쓴다**(웃음 포인트). 도트·만화풍 동물, 그리고 **고블린·오크 같은 뜬금없는 상대**도 적당한 무료 그림이 있으면 넣는다.
- 비중: 일반 출몰의 약 5~8%를 "수상한 손님" 분류로(드물게 등장, 도감 별도 탭, 전용 한마디). 종 상성은 중립, 전용 기술 2~3개.
- 자산은 CC0 우선, 출처를 `docs/pet-credits.md`에 기록한다.

## 아이템 (사용자 결정, 2026-11-11)
- **착용 아이템(옷·목줄·장식 등)은 스탯이 없다. 디자인(겉모습)만.** 초안의 스탯 장비·확정 강화·등급·제작은 **폐기**한다. 엔진의 장비 보정 기능은 쓰지 않는다(상대도 동일).
- 힘의 원천은 레벨·스탯 분배·직업·기술·숙련도·컨디션·**소모품**이다. 코인 소비처는 옷(꾸미기)과 소모품, 전직 비용.
- **전투 소모품**: 내 턴에 "가방"에서 하나 쓰면 그 턴 행동을 쓴다. 한 판에 가져가는 수는 3개까지(종류 무관), 상대(주인 있는 동물)도 소모품을 쓸 수 있고 예고에 보인다.

| 분류 | 예시(이름은 구현 때 확정) | 효과 시작값 | 가격 시작값 |
|---|---|---|---|
| 회복 | 작은/보통/큰 물약 | 버틸 힘 20% / 35% / 50% 회복 | 15 / 35 / 70 |
| 기력 | 시원한 물 / 기운 음료 | 기력 +3 / +6 | 12 / 30 |
| 강화 | 힘나는 간식 / 든든한 간식 / 날쌘 간식 / 또렷한 간식 | 공격력·방어력·민첩·집중 +20%, 3라운드 | 각 25 |
| 해제 | 정신 번쩍 껌 | 상태 이상 모두 해제 | 20 |
| 보호 | 푹신한 방석 | 다음 한 번의 피해 50% 감소 | 30 |
| 급소 | 집중 사탕 | 다음 공격 크리티컬 확정 | 40 |
| 탈출 | 장난감 공 | 상대 시선을 끌어 그 라운드 상대 행동 취소(대장급에는 무효) | 35 |
| 버티기 | 끈기 리본 | 그 판에 한 번, 쓰러질 피해를 버틸 힘 1로 버팀 | 60 |

- 한 판의 회복 총량 상한(최대 버틸 힘의 60%)과 같은 강화 중복 금지로 장기전·무한 회복을 막는다. 시뮬레이션으로 소모품 유무의 승률 차이가 +15%p 안에 들게 조정한다.
- 소모품은 강아지별 가방에 담고(코인은 공용), 상점에 "전투 용품" 분류를 추가한다. 승리 시 낮은 확률로 소모품을 줍는다.

## 방어의 재미와 읽기 싸움 (2026-11-11, 사용자 요청: "피해 줄이기만이면 그냥 공격이 낫다")
참고한 장르 관습: 대전 격투의 공격/가드/잡기 삼각, 액션 게임의 패링·저스트 가드, 덱 빌딩 게임의 방어도+자원 회수, 턴제 RPG의 액션 커맨드(타이밍 입력), 필살기 게이지.

1. **삼각 관계**: 공격은 준비(충전·보조)를 끊고, 방어는 공격을 받아치고, **흔들기(가드 브레이크)**는 방어를 뚫는다. 무엇을 낼지 서로 읽는 싸움이 된다.
2. **방어 기술을 네 갈래로**
   - 막기: 피해 −60% + **기력 +1 회수**(안전한 선택).
   - 받아치기: 상대가 접촉 공격이면 피해 0 + **반격**(방어력 기반 피해). 상대가 공격하지 않으면 헛돌아 다음 라운드 빈틈(받는 피해 +25%). 고위험 고보상.
   - 흘리기: 충전형·결정기를 완전히 피하고 상대 기력 −2. 연속형에는 약함.
   - 버티기 태세: 2라운드 동안 피해 −30% + 상태 이상 면역.
3. **흔들기 기술**(공격·보조 쪽): 방어 중인 상대에게 방어 무시 + 1라운드 "휘청"(방어 기술 사용 불가). 방어하지 않은 상대에게는 약함.
4. **예고의 불확실성**: 일반 상대의 예고는 지금처럼 정확. 대장급·영리한 기질은 가끔 **속임수**(예고는 종류만 "공격 계열"로 흐리게, 또는 낮은 확률로 다른 행동) — 눈치챌 단서(대사·자세)를 준다.
5. **타이밍 입력(액션 커맨드)**: 상대 공격이 들어오는 순간 줄어드는 고리에 맞춰 탭하면 **딱 막기**(추가 −20%, 완벽하면 기력 +1과 전용 연출). 내 공격 때 맞춰 탭하면 **힘 싣기**(+10%). 실패해도 불이익 없음. 설정에서 끌 수 있고, 모션 줄이기에서는 자동 "보통" 판정.
6. **기세 게이지**: 받아치기 성공·딱 막기·크리티컬·상성 좋은 타격으로 차오른다. 가득 차면 **결정기**(직업·품종 시그니처)를 기력 없이 한 번 쓸 수 있다. 전용 컷인.
7. **연속 방어 약화**는 유지(같은 방어를 연달아 쓰면 효과 절반).
8. 시뮬레이션 목표: 방어 계열을 섞는 정책이 공격만 하는 정책보다 동급 승률 +5~12%p. 받아치기 성공률은 읽기 정책 기준 40~60%.

## 상성은 개체마다 무작위 (사용자 결정, 2026-11-11)
- **종·품종에 상성을 묶지 않는다.** 초안의 "종 단위 상성 6개 움직임 유형"은 폐기. 종·품종은 스탯·체급·고유 기술·외형만 정한다.
- 상성 체계는 기존 **6기운**(돌진·기교·추적·수호·교감·지구)과 6×6 표(유리 1.30 / 보통 1.00 / 불리 0.75)를 쓴다. 각 기운은 2개에 유리, 2개에 불리.
- **개체마다 기운 하나를 무작위로**(개체 시드로 고정: 같은 개체는 언제 만나도 같은 기운). 같은 진돗개라도 어떤 녀석은 돌진, 어떤 녀석은 교감. 그래서 우연히 만난 상대가 나에게 유리할 수도 불리할 수도 있다.
- 전투 규칙: ① 공격 기술의 기운 × 상대의 기운으로 배율 ② **자기 기운과 같은 기운의 기술은 위력 +15%**(기운 일치) ③ 개체는 자기 기운 기술 2~3개 + 종·품종 고유 기술 + 공통 기술을 가진다(그래서 상대 기운을 알면 어떤 기술이 올지 짐작된다).
- 화면: 조우 카드와 대결 화면의 이름 옆에 기운 아이콘. 내 강아지 기준 "유리 ▲ / 불리 ▼" 한눈 표시. 지도의 동물 표시에도 기운 색 점(가서 싸울지 고르는 재미).
- 도미·미네의 기운은 고정(도미 교감, 미네 기교)이되, 다른 기운의 기술도 배워서 불리한 상대에게 대응할 수 있다. 네임드는 기운을 사연에 맞게 지정.
- 시뮬레이션: 유리/보통/불리 상대별 동급 승률 목표 약 75 / 62 / 45%(불리해도 기술 선택과 방어로 이길 수 있게).

## 기술 단위 상성과 개체의 약점·내성 (사용자 결정, 2026-11-11)
- 기술마다 **기운**(6기운 중 하나, 공통 기술은 무기운)과 **형태 태그**(접촉 / 소리 / 냄새 / 속임 / 연속 / 충전 / 시선 중 1~2개)를 가진다.
- 1차 상성: 기술의 기운 × 상대 개체의 기운(1.30 / 1.00 / 0.75).
- 2차 상성: 개체마다 무작위로 **약점 태그 하나**(그 형태의 기술에 ×1.25)와 **내성 태그 하나**(×0.8)를 가진다(개체 시드로 고정). 두 상성은 곱하되 0.6~1.6으로 제한.
- 약점·내성은 **처음에는 숨겨져 있다.** 해당 형태의 기술을 한 번 맞히면 "유독 잘 통했다!" / "잘 버텨 낸다…"와 함께 밝혀지고, 그 개체의 도감 카드에 기록된다(다음에 만나면 처음부터 보인다). 상세 보기 카드에서 밝혀진 것만 표시.
- 기술 버튼의 상성 표시(▲/▼)는 알려진 정보만 반영한다. 모르는 약점은 "?" 없이 그냥 기운 기준으로.
- 도미·미네에게도 약점·내성 태그가 하나씩 있고(고정), 상대도 이를 노릴 수 있다.
- 같은 기운이라도 형태가 다른 기술을 골고루 배우게 해, "이 상대에게는 유독 이 기술"이 생기도록 한다.

## 상대의 기술과 지능 (사용자 결정, 2026-11-11: "상대가 멍청하게 싸우면 안 된다")
- 상대도 우리와 **같은 규칙으로 레벨에 따라 기술을 배운다**(공통 + 자기 기운 + 종·품종 고유, 레벨이 오르면 주력기·결정기·방어·보조가 늘고 장착 4~6개를 스스로 고른다). 레벨이 높은 상대는 충전형·연속형·흔들기·받아치기까지 쓴다.
- **AI가 고려하는 것**: ① 내 기술의 기운·형태와 상대(우리)의 기운·알려진 약점 ② 남은 기력(숨 고르기 시점, 결정기를 위한 저축) ③ 우리 체력(마무리 가능하면 마무리) ④ 우리가 직전에 한 행동의 버릇(방어를 자주 쓰면 흔들기, 공격만 하면 받아치기) ⑤ 자기 체력(위급하면 막기·회복·소모품) ⑥ 상태 이상·강화 타이밍 ⑦ 기세 게이지.
- **영리함 등급**(개체의 기질·서열에 따라): 순둥이(실수 30%, 한 수 앞만) / 보통(실수 15%) / 노련(실수 5%, 버릇 읽기) / 대장(실수 거의 없음, 속임수 예고, 소모품 사용) / 싸움왕(전 기능 + 페이즈 변화). 실수 = 차선책을 고르는 확률. 완벽한 기계처럼 보이지 않게 기질별 버릇(성급한 녀석은 결정기를 일찍, 신중한 녀석은 방어를 자주)을 둔다.
- 예고는 유지하되(우리도 읽을 수 있게), 노련 이상은 우리의 예고된 대응을 한 번 더 읽는다.
- 시뮬레이션: 같은 레벨에서 등급별 플레이어(탐욕 정책) 승률 목표 — 순둥이 80%, 보통 65%, 노련 50%, 대장 35%(대장은 준비·소모품·상성으로 넘는 벽).
