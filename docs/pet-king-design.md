# 동네 싸움왕 — 최종 결정 (2026-11-11)

세부 표(10구역, 개 32견종·고양이 12형·야생 10종×2형, 512개체 생성 규칙, 네임드 35마리, 5직업·전용 기술 30개, 장비, 칭호, 공동 대장, 경제, v17 스키마, 8단계 로드맵)는 `docs/pet-king-design-codex.md`가 기준 자료다. 아래와 다르면 **이 문서가 우선**이다(사용자 결정 포함).

## 뼈대 (Codex 초안 채택)
- 목표: 도미·미네가 동네 싸움왕에 오른다. 100칸을 10개 구역(2열×5행)으로 묶고, 칸 대장 → 구역 대장(Lv.10~64) → 길목 강자 4 → 현 싸움왕.
- 동물: 12종(개 32견종, 고양이 12형, 비둘기·까치·참새·오리·청설모·너구리·고라니·멧돼지 등 10종×2형). 개체는 이름·별명·주인 유무·외형 변형(털·색·흉터·옷·소품)으로 512마리 + 네임드 35마리. 그림은 기본 그림 위에 레이어를 겹쳐 늘린다.
- 레벨 상한 999. 누적 XP `C(L) = 6(L−1)(L+4) + floor(max(0, L−10)³/25)`.
- 직업 5개(돌격·수비·기교·추적·교감), 전직 3단계(Lv.10/30/60, 구역 인증 조건), 직업 보정 최대 +8%/+8%/−8%.
- 스탯 6개, 레벨당 포인트 3점, **재분배 불가**(사용자 결정).
- 장비 확정 강화(실패·파괴 없음), 칭호, 동물 도감 보상, 공동 구역 대장(친구들의 기여 누적), 서열 랭킹. 퀘스트·출석 없음.
- 전투 계산은 클라이언트, 서버는 티켓·정산·성장 저장. 접속은 이름 입력 그대로. **SQL은 v17 한 번**을 목표.

## 사용자 결정으로 초안과 달라지는 것
| 항목 | 초안 | 최종 |
|---|---|---|
| 돌보기와 전투 | 세 수치 60 이상이면 XP +10% | **컨디션 감소**: 배부름·기분·청결이 부족하면 능력치 %감소(수치별 40~59 −5%, 20~39 −10%, 20 미만 −15%, 합산 최대 −30%). 상대 동물도 개체별 컨디션을 가지며 전투 전 카드에 표시 |
| 출몰 | 명단 고정 배치 | 명단(개체)은 고정이되 **출몰은 무작위**: 30분 구간마다 칸별 30% 확률, 한 칸에 0~여러 마리, 빈 칸 있음. 네임드는 정해진 칸·조건 |
| 조우 | 겨루기 버튼 | 지도에서 "동물 보기"로 확인 → 이동 → **장면의 동물을 눌러** 카드(이름·레벨·주인·컨디션) 확인 후 겨루기. 겨루기 버튼은 항상 보이고, 없으면 "여긴 겨룰 상대가 없어요" 안내 |
| 승리 후 | 하루 1회 보상 | **이기면 그 동물은 자리를 뜬다**(그 구간 동안 사라짐, 모두에게 — v17). 지거나 그만두면 남아서 재도전 가능 |
| 크리티컬 | 없음 | **도입**: 기본 5% + 집중 보정(상한 25%), 피해 ×1.5, 방어 중인 상대에게는 없음. 전용 연출 |
| 기술 | 24 + 직업 30 | **대폭 확대**: 공통 / 종 고유 / 품종 시그니처(견종·묘종별 1~2개) / 직업 기술. 기력 0~8로 다양화(견제 0~1, 주력 2~4, 결정기 5~8, 충전형·연속형·반동형) |
| 연출 | — | 기술마다 고유 연출 + 전용 이펙트 그림. 급소·보스 등장·전직·레벨업 컷인 |
| 다른 사람에게 보이기 | — | 중계 알림("○○님이 도미로 △△와 겨루는 중") + 이력에 결과 한 줄. 실시간 관전 없음 |
| 문구 | — | 중복 없이 꼭 필요한 것만 |

## 외부 무료 자산 (사용자 제안)
- 이펙트·아이콘·UI는 무료 공개 자산을 적극 쓴다. **CC0(표기 불필요)** 우선: Kenney(kenney.nl), OpenGameArt의 CC0 묶음. **CC BY**(game-icons.net 등)는 화면의 "만든 이들" 목록에 출처를 적는다. 라이선스가 불분명한 것은 쓰지 않는다.
- 쓰는 자산은 `docs/pet-credits.md`에 이름·출처·라이선스를 기록한다.
- 동물 그림은 기존 실사풍과 맞아야 해서 Codex 생성(기본 그림 + 레이어)을 기본으로 한다.

## 구현 순서 (병렬로 나눈다)
1. **엔진 기반**(SQL 없음): 999레벨·성장식·분배 계산, 크리티컬, 컨디션 감소, 기력 0~8 기술 운용 타입, 종·서식지 상성, 시뮬레이션.
2. **콘텐츠 데이터**(SQL 없음, 1과 병렬): 종·품종 표, 개체 생성기(512), 네임드, 확대된 기술 표, 직업 트리.
3. **그림**(병렬): 개 20, 고양이 12, 야생 20, 레이어(흉터·옷·소품), 기술 이펙트·아이콘(무료 자산 + 생성).
4. **v17 SQL 한 번**: 성장·분배·숙련도·직업·장비·티켓·정산·출몰 처치 공유·중계·이력·공동 대장.
5. **화면**: 장면 속 동물 조우, 스탯·기술·직업 창, 도감, 서열, 공동 대장, 컷인 연출.

## 이질적인 그림과 엉뚱한 상대 (사용자 결정, 2026-11-11)
- 그림풍이 맞지 않는 무료 자산도 **일부는 일부러 쓴다**(웃음 포인트). 도트·만화풍 동물, 그리고 **고블린·오크 같은 뜬금없는 상대**도 적당한 무료 그림이 있으면 넣는다.
- 비중: 일반 출몰의 약 5~8%를 "수상한 손님" 분류로(드물게 등장, 도감 별도 탭, 전용 한마디). 종 상성은 중립, 전용 기술 2~3개.
- 자산은 CC0 우선, 출처를 `docs/pet-credits.md`에 기록한다.

## 아이템 (사용자 결정, 2026-11-11)
- **착용 아이템(옷·목줄·장식 등)은 스탯이 없다. 디자인(겉모습)만.** 초안의 스탯 장비·확정 강화·등급·제작은 **폐기**한다. 엔진의 장비 보정 기능은 쓰지 않는다(상대도 동일).
- 힘의 원천은 레벨·스탯 분배·직업·기술·숙련도·컨디션·**소모품**이다. 코인 소비처는 옷(꾸미기)과 소모품, 전직 비용.
- **전투 소모품**: 내 턴에 "가방"에서 하나 쓰면 그 턴 행동을 쓴다. 한 판에 가져가는 수는 3개까지(종류 무관), 상대(주인 있는 동물)도 소모품을 쓸 수 있고 예고에 보인다.

| 분류 | 예시(이름은 구현 때 확정) | 효과 시작값 | 가격 시작값 |
|---|---|---|---|
| 회복 | 작은/보통/큰 물약 | 버틸 힘 20% / 35% / 50% 회복 | 15 / 35 / 70 |
| 기력 | 시원한 물 / 기운 음료 | 기력 +3 / +6 | 12 / 30 |
| 강화 | 힘나는 간식 / 든든한 간식 / 날쌘 간식 / 또렷한 간식 | 공격력·방어력·민첩·집중 +20%, 3라운드 | 각 25 |
| 해제 | 정신 번쩍 껌 | 상태 이상 모두 해제 | 20 |
| 보호 | 푹신한 방석 | 다음 한 번의 피해 50% 감소 | 30 |
| 급소 | 집중 사탕 | 다음 공격 크리티컬 확정 | 40 |
| 탈출 | 장난감 공 | 상대 시선을 끌어 그 라운드 상대 행동 취소(대장급에는 무효) | 35 |
| 버티기 | 끈기 리본 | 그 판에 한 번, 쓰러질 피해를 버틸 힘 1로 버팀 | 60 |

- 한 판의 회복 총량 상한(최대 버틸 힘의 60%)과 같은 강화 중복 금지로 장기전·무한 회복을 막는다. 시뮬레이션으로 소모품 유무의 승률 차이가 +15%p 안에 들게 조정한다.
- 소모품은 강아지별 가방에 담고(코인은 공용), 상점에 "전투 용품" 분류를 추가한다. 승리 시 낮은 확률로 소모품을 줍는다.
